Model Information

How the Prediction Works

This system uses an ensemble machine learning model trained on 545 real estate transactions. Two algorithms were compared — Random Forest outperformed Linear Regression by 13% in R² accuracy and was selected as the production model.

Data Pipeline

From Raw Data to Prediction

1

Data Collection

545 housing records with 13 features including area, bedrooms, bathrooms, furnishing status, and amenities.

Housing.csv
2

Data Cleaning & EDA

Exploratory analysis in Jupyter Notebook. Handled missing values, selected 6 most impactful features, exported cleaned CSV.

Cleaned_data.ipynb
3

Feature Engineering & Encoding

LabelEncoder for categorical columns (furnishingstatus, airconditioning). StandardScaler for numeric normalization.

train.py
4

Model Training & Evaluation

80/20 train-test split. Trained Linear Regression (R²=0.76) and Random Forest (R²=0.89). Best model saved with joblib.

model.pkl · scaler.pkl
5

Web Deployment

Flask app loads model at startup, serves HTML form, predicts on POST request, and displays result with price range.

app.py
